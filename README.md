# cli-student-record-system
A terminal-based Student Record Management System written in C, implementing file-based persistence, dynamic memory management, and an ANSI-colored CLI using a Singly Linked List architecture.

## Features

- Add student records
- Delete student records
- Modify student records
- Display student records
- Sort records
- Reverse linked list
- Delete all records
- Save records to a file
- Load records from a file

## Concepts Used

- C structures
- Singly linked lists
- Pointers
- Dynamic memory allocation
- File handling
- Modular programming
- Makefile
- `malloc()` / `free()`
- `fopen()` / `fscanf()` / `fprintf()`
